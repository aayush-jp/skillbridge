# SkillBridge

An AI-powered career development platform that analyses your resume, identifies skill gaps against your target role, and generates a personalised learning path to close them.

## What it does

1. **Onboarding** — pick your target domain and role (e.g. ML Engineer, Frontend Engineer)
2. **Resume analysis** — upload a PDF or DOCX; Gemini extracts your skills and produces a readiness score
3. **Skill gap report** — side-by-side view of skills you have vs skills to build, with priorities
4. **Learning path** — AI-generated curriculum of modules, resources, and estimated hours
5. **Assessments** — per-skill quizzes generated by Gemini to validate your progress
6. **Dashboard** — streak calendar, progress tracking, quick stats

## Environment variables

Copy `.env.example` to `.env.local` and fill in the values before running locally.

| Variable | Description |
|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | Supabase project URL |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | Supabase anonymous/public key |
| `SUPABASE_SERVICE_ROLE_KEY` | Supabase service role key (server-only, keep secret) |
| `GEMINI_API_KEY` | Google AI Studio API key |

**Where to get them:**
- **Supabase** → project dashboard → *Settings → API*
- **Gemini** → [Google AI Studio](https://aistudio.google.com/app/apikey)

## Local setup

### Prerequisites

- Node.js 20+
- A Supabase project (free tier is fine)

### Steps

```bash
# 1. Clone and install
git clone https://github.com/your-username/skillbridge.git
cd skillbridge
npm install

# 2. Configure environment
cp .env.example .env.local
# Open .env.local and fill in all four variables

# 3. Apply database migrations
# Option A — Supabase CLI
supabase link --project-ref your-project-ref
supabase db push

# Option B — paste the SQL manually in the Supabase SQL editor
# File: supabase/migrations/001_initial_schema.sql

# 4. Create the resume storage bucket
# Supabase dashboard → Storage → New bucket
# Name: resumes  |  Public: true

# 5. Start the dev server
npm run dev
# App is at http://localhost:3000
```

## Deployment guide (Vercel)

### 1. Push to GitHub

```bash
git add .
git commit -m "initial commit"
git push origin main
```

### 2. Import on Vercel

1. Go to [vercel.com/new](https://vercel.com/new)
2. Import your GitHub repository
3. Vercel auto-detects the **Next.js** framework preset — no build changes needed

### 3. Set environment variables

In *Project Settings → Environment Variables* add all five variables from `.env.example`.

| Variable | Environments |
|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | All |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | All |
| `SUPABASE_SERVICE_ROLE_KEY` | Production, Preview |
| `GEMINI_API_KEY` | Production, Preview |

### 4. Deploy

Click **Deploy**. The `vercel.json` in this repo already sets a 60-second timeout on all AI API routes.

### 5. Configure Supabase for the production URL

In your Supabase project → *Auth → URL Configuration*, add:

```
Site URL:      https://your-app.vercel.app
Redirect URLs: https://your-app.vercel.app/**
```

Replace `your-app.vercel.app` with your actual deployment URL.

## API routes

| Route | Method | Description | Timeout |
|---|---|---|---|
| `/api/parse-resume` | POST | Parse PDF/DOCX, upload to storage, save to DB | 60 s |
| `/api/skill-gap` | POST | Gemini analysis: readiness score + skill gaps | 60 s |
| `/api/learning-path` | POST | Gemini: generate or retrieve learning path | 60 s |
| `/api/assessment/generate` | POST | Gemini: generate 10 MCQ questions for a skill | 60 s |

All routes require a valid Supabase session cookie (enforced via `getUser()`).
